### v2.1.0 (2026-08-16)

#### 🎯 Tier 1: Quick Wins

- **Prometheus metrics endpoint** (`/metrics`) - Added Flask app with `/metrics` endpoint exposing `draco_version`, `draco_reduction_target`, `draco_quality_threshold`, `draco_mandates_pass`, `draco_phases_completed`, `draco_phases_total`, `draco_system_healthy` in Prometheus text format. Root endpoint `/` returns health summary JSON.

- **Enhanced README badges** - Added Prometheus Metrics (`orange.svg` → `/metrics`) and Flask Dashboard (`blue.svg` → `/`) badges to README. All existing badges (PyPI, npm, License, Python, TypeScript, Docker, Quality Gates, Token Reduction, codecov) preserved.

- **Agent YAGNI Ladder Mermaid visualization** - Added `### 📊 Agent YAGNI Ladder` section with full Mermaid flowchart showing L1-L6 agent levels with reduction caps and quality minima. Uses color-coded nodes: L1 (green), L2 (blue), L3 (orange), L4 (green), L5 (purple), L6 (amber). Fixed Mermaid rendering by removing `%%{init...}%%` block that caused "No diagram type detected" error.

- **Property-based test skeleton** (`tests/test_properties.py`) - Created 27 Hypothesis property-based tests across all core modules: `count_tokens`, `analyze_text`, `apply_basic_reduction`, and ZON formatting. Covers non-negative results, consistency, type validation, quality ranges, ZON roundtrip, depth validation, and edge cases.

- **Optimized Docker health check** - Updated HEALTHCHECK to fallback to Python check if `draco health` command fails: `CMD draco health || python3 -c "from draco.dashboard import quick_health_check; print('unhealthy')" || exit 1`.
